LinkedIn Profile API

Give it a LinkedIn profile URL, get structured JSON back. Machine-readable schema at /openapi.json.

Endpoints

EndpointPurpose
GET /profileProfile as structured JSON
GET /rawSemantic outline before field mapping (debug)
GET /healthLiveness and session status

Parameters

NameDefaultDescription
urlrequiredProfile URL, /in/<name> path, or bare vanity name
include_activityfalseAlso fetch recent posts (adds several MB)
refreshfalseBypass the cache

Send X-API-Key only if the deployment sets API_KEYS.

Example

curl "$HOST/profile?url=https://www.linkedin.com/in/williamhgates/"

Errors

Every error is {"error", "code", "detail"}. 503 session_expired means the backing LinkedIn cookies need refreshing.

Notes

Fields are omitted when the page did not render them — absent is not the same as “the member has none”. What renders depends on the backing account’s network distance to the member. meta reports which cards came back and which sections were recognised.
